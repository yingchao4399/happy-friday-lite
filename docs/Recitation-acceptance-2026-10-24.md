# 背诵音频开发验收

版本为 3.0.6-preview.2 独立开发副本，未修改已安装 3.0.6 或真实用户数据库；不能视为最终安装验收。

## 已通过的真实运行链路

- Windows 合成中文 WAV、系统本机识别实际执行，10.191 秒生成三段转写，保存时间戳和置信度。合成句中的“知识”被识别为“继续”，因此保留原始结果并提供校对入口，不把语音识别视为可靠原文。
- `scripts/probe-recitation-ui.mjs` 使用真正 Vue 页面、正式 preload 和 `recitation-ipc.js`，通过文件 input 导入音频，受管 Blob 解码和播放，完成转写、分析、计划、三种题型及来源回跳。
- 人工逐段校对后重新生成分析和练习，保存原始文本/片段/时间/置信度；取消编辑不写入，旧版本校对拒绝覆盖。数据库与页面重开保持结果。
- 640px 布局、重试转写时取消通过；取消保留此前已校对有效结果，释放活动任务。
- `task-progress` 提供校验、转写、分析、生成练习、保存、完成阶段；取消、能力错误包含原因、下一步和可恢复状态，不向事件发送正文。
- 公共 IPC 传参改为解开 Vue reactive proxy，保留二进制、Map/Set、循环和共享引用，修复保存时 `An object could not be cloned`。不能用 JSON 序列化替代二进制传输。
- DeepSeek 官方聊天模型不作为转写模型；已知不支持音频的模型在调用前拒绝，未知服务仍需实际验证。时间戳和置信度校验拒绝非法结果，不伪造缺失置信度。

证据在 `app-data/diagnostics/recitation-ui.log`、`recitation-speech-source.log`、`recitation-core-tests.log`；截图为 `recitation-transcript-correction-ui.png` 和 `recitation-analysis-ui.png`。上一轮全量 Node 回归 104/104，前端构建通过（25.36 秒，存在体积警告）。

## 范围及未完成门禁

- 当前学习内容通过本机规则抽取段落、关键词和题目，仍须检查长篇、真实口音、噪音及用户常用编码的效果；不能声称已完成高质量大模型学习分析验收。
- 无参考文本只报告连贯性/节奏，不给准确率；重复片段提供计算依据，不把一段录音称为已准确背诵多遍。
- 云端或其他本地模型仍须按可用实际配置完整验收；DeepSeek 聊天 API 不能代替语音服务。
- 真正安装版的导入、转写、播放、分析、出题、取消、历史重开和升级/回退仍待验收。
