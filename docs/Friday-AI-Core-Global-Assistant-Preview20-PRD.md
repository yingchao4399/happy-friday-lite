## 1. 产品定义

Friday AI Core 是 Happy Friday Lite 的应用级 AI 控制层。本轮目标是把 Friday 对话、笔记 Word 导出、Office 能力、MCP/DSH 请求和根级全局助手逐入口接入同一套请求、能力、任务、权限、事件和结果合同。全局助手是 Core 的 UI Adapter，负责让用户在切换页面后继续查看任务状态、处理审批、暂停、继续或取消任务。当前聊天入口并未全部经过 TaskRuntime，需按入口台账核验。

本版本的用户感受应当仍然是原版 Friday：原有对话、笔记、Office 和 Typewriter 的布局、输入方式、菜单和焦点行为保持不变。新增能力以辅助层嵌入，只有在任务确实需要授权或恢复时才出现。本文同时规定计划中 Epic A-H 的发布验收；代码中出现入口不等于用户旅程完成。

## 2. 用户问题与目标

当前版本的 AI 入口分散在对话、Office、笔记导出和 MCP 中，用户无法稳定知道任务是否真的执行、写入了什么、是否能撤销，也无法在切换页面后找到后台任务。用户还反馈了已连接 DeepSeek 时误报网络故障、Office 助手无法连接、Dock 遮挡且拖不动/展开卡顿/缺输入框、各窗口历史不能像 DeepSeek 侧栏逐条打开、Typewriter 卡顿和图片不显示。目标是解决以下问题：

1. 统一请求的 actor、space、session、thread、request 和 task 边界。
2. 写能力先展示计划和影响范围，再经过 scope 与审批检查。
3. Word 写入必须回读验证，失败时保留步骤和可执行的恢复动作。
4. 任务可在能力步骤边界暂停、继续和取消，重复继续不重做已确认步骤。
5. 根级全局助手跨路由投影任务事实，不抢占编辑器和 Office 焦点。
6. 网络错误提供分类、有限重试和脱敏诊断；流中断保留局部结果并支持安全重试。
7. 手动会话标题优先于异步自动标题，重试请求不重复保存用户消息。
8. 主对话、Office、笔记、知识库、日程和 Dock 各自提供可选、可恢复、可续聊的独立会话历史；Office 包含 Docs、Sheets、Slides，并对 PDF 单独验收。
9. Dock 可在应用内容区拖动、记忆位置、快速展开并直接输入；设置可控制显示、形象、分身模式和 Agent。Agent 切换若未接入后端，必须明确显示真实限制。
10. Typewriter 的输入性能、声音恢复和图片跨视图显示可用；Obsidian 插件状态与可运行能力有真实证据。

### 3.2 本版边界

- 全局助手是 Friday 窗口内的跨路由 Dock，不承诺操作系统级悬浮窗、托盘或系统全局快捷键。
- DSH 不能从 Core 继承 Friday 全局空间和写 scope；没有可靠空间/授权字段时降级为只读。
- Core v1 不暴露 Shell、Python、pip、任意网络写入、剪贴板、UI 控制和 Office 批处理等高影响旁路。
- Typewriter 性能/声音/图片、Obsidian 兼容矩阵、完整历史迁移和安装版回退属于本轮发布门禁。任何未通过项目都不能靠已有 Dock 或局部源码测试替代，也不能先生成最终安装包。

## 4. 用户故事与验收

### US-01：笔记写入 Word

**Given** 用户打开一篇笔记并选择导出 Word，**When** 选择输出路径，**Then** Friday 创建 Core task 并显示写入目标、笔记标题和授权确认。

**When** 用户批准，**Then** Core 通过 `note_to_word` 读取笔记、创建 Word、写入来源标记、回读并检查目标文件存在且非空；结果返回 taskId、输出路径、来源 URI、验证状态和 undoAction。

**When** 用户拒绝，**Then** task 进入 `cancelled`，不创建文件；用户可继续编辑笔记。

**When** 目标文件已存在、Office 正在打开目标或 CLI 失败，**Then** task 不显示完成，错误带阶段和可操作原因，已完成步骤仍可查询。

### US-02：任务暂停与继续

**Given** task 正在运行，**When** 用户点击暂停，**Then** Core 设置 pauseRequested，并在当前能力完成后的检查点进入 `paused`。

**When** 用户继续，**Then** Core 重建计划，跳过已有 stepId/capabilityId 回执，不重复写入已成功的能力。

**When** 应用已重启导致临时请求正文不存在，**Then** 继续命令明确返回重新提交提示，不猜测或自动执行旧写入。

### US-03：全局助手

**Given** 用户在任意主路由，**When** 点击 Friday 全局助手入口，**Then** Dock 显示当前 actor 的最近任务、状态、失败摘要和可用动作。

**When** 用户切换路由或关闭 Dock，**Then** 后台 task 继续按 Core 事实运行，重新打开 Dock 能看到同一 taskId。

**When** 用户点击审批、暂停、继续或取消，**Then** Dock 只调用 Core IPC，不直接修改业务资源或绕过确认弹窗。

**When** 用户拖动折叠入口或面板标题栏，**Then** Dock 在应用可用区域内跟随指针并保存位置；重新打开、路由切换和窗口缩放后仍可见。展开响应不能明显阻塞正文、Office 输入或焦点。

**When** 用户直接在 Dock 输入或选择一条历史，**Then** 当前消息在 Dock 内显示，旧记录在 Dock 内恢复，后续消息追加到该 session，不跳转主对话。

### US-04：只读与外部调用

**Given** DSH/MCP 客户端只有 `read`，**When** 请求写能力，**Then** plan 阶段返回 scope 拒绝，不能靠 prompt 或参数伪造审批。

**When** DSH 请求带有外部 workspace，**Then** spaceId 保留为 `external:dsh:<workspace>`，actor 与 Friday 用户隔离。

### US-05：网络中断和重试

**Given** 请求尚未产生模型输出且没有副作用，**When** DNS、代理、TLS、超时、429 或 5xx 短暂失败，**Then** Core 按有限次数和 Retry-After 重试。

**When** 4xx 鉴权/参数错误或已有流式正文，**Then** 不盲目重放；前端保留错误/局部内容并提供显式重试。

**When** 用户点重试，**Then** 原用户消息 ID 可复用，不产生重复用户记录。

### US-06：标题

**Given** 会话尚未人工命名，**When** 异步标题生成完成，**Then** 自动标题更新会话列表。

**When** 用户已手动命名，**Then** 晚到的自动标题不修改标题或时间戳。

**When** Office 新文档已有用户标题、正文标题或文件名，**Then** 显示标题按确定的优先顺序选取；自动建议不重命名磁盘文件、不覆盖用户编辑的正文标题。

### US-07：六类窗口的独立历史

| 窗口 | 历史范围 | 必须恢复的内容 |
| --- | --- | --- |
| 主对话窗口 | Friday 普通会话 | 消息、附件引用、会话标题、模型和中断/任务状态 |
| Office Agent 窗口 | 当前 Docs、Sheets、Slides 文件各自独立；PDF 单列验收 | 该文档的消息、工具结果、Agent 上下文和原文件绑定 |
| 笔记 AI 窗口 | 当前笔记；未保存草稿有稳定临时身份 | 消息、笔记资源身份和继续对话所需上下文 |
| 知识库对话窗口 | 当前知识库/目录；普通问答与 Agent 各自独立 | 消息、引用、范围和选定会话 |
| 日程安排 AI 窗口 | 日程 Agent 独立范围 | 消息、相关日程上下文和原 session |
| Dock 对话窗口 | `friday-dock` 独立范围 | 消息、当前 session、关联 task 状态 |

**Given** 同一窗口有多条会话，**When** 打开历史，**Then** 显示可扫描的列表（标题、最近活动时间、选中态、空态），可搜索并新建；点击哪条就只加载该条，不能只弹出当前 transcript。

**When** 用户从旧会话继续发送，**Then** 复用原 session ID，消息按顺序追加；关闭并重开该窗口后仍能选回。快速连续点击不同条目时，只能显示最后选中的结果。

**When** 用户切换 Office 文件、笔记或知识库目录，**Then** 当前范围列表不混入其他资源；旧会话、旧附件和工具输出仍能从原范围读取。删除、归档、重命名、置顶和恢复的持久化行为按迭代方案 Epic B 验收，未实现时不得标记历史完整。

### US-08：DeepSeek 与 Office 联网

**Given** Friday 主窗口已选中可用 DeepSeek 模型，**When** 用户在 Office Agent 发送消息，**Then** Office 使用同一有效模型配置并能收到流式回复；配置尚未同步时应提示配置未就绪，而不是误称本机断网。

**When** 服务端返回 401、403、429、模型名错误、5xx 或代理/TLS/连接失败，**Then** 界面保留准确的错误类别、HTTP 状态和请求 ID，提供相应修复或重试操作；只有真实传输故障才显示网络连接故障。

**When** 已产生 token 或执行工具，**Then** 中断后保留局部正文和已执行回执，不自动重发写操作。模型连接测试必须针对当前模型端点，而不是仅判断系统在线。

### US-09：Typewriter 输入、声音和图片

**Given** 用户打开长文、频繁切路由或使用中文输入法，**When** 连续打字，**Then** 输入、选区、撤销栈和保存不丢；冷启动可输入 P95 不超过 2 秒、输入到内容更新 P95 不超过 50 毫秒、返回页面 P95 不超过 1 秒，实测基线和测试机器记录在报告中。

**When** 用户空闲后再次输入，**Then** 文字不等待音效；本地音效首键和空闲恢复 P95 不超过 100 毫秒。关闭声音时音频路径不影响输入。

**When** 用户粘贴、拖入或选择图片，**Then** 正文插入稳定受控 URI，预览、普通笔记视图、保存重开均显示；大图延迟加载且不阻塞输入，失效/越权资源显示可理解的占位与重试。

### US-10：全局助手设置与真实 Agent 路由

**Given** 用户在设置中选择隐藏/显示、默认/简洁形象、Friday/Researcher/Auto 分身模式和 Agent，**When** 保存并重启应用，**Then** 设置保持且 Dock 的显示和外观即时变化。

**When** 用户切换 Agent 再发起新对话或任务，**Then** 新请求应进入所选 Agent 的真实后端；正在运行的旧任务保持原 owner。若后端尚无相应 Agent，界面必须明确说明当前由 AI Core 自动调度，不能把 UI 选择展示为已实际切换。

### US-11：Obsidian 插件可运行

**Given** 用户下载受支持的插件，**When** 校验 manifest、版本和权限后启用，**Then** 插件 host 真实运行，命令/设置可用；停用后事件、命令和资源全部清理。

**When** 插件失败、更新不兼容或主应用重启，**Then** 可查看失败 API/阶段、回退旧版本并保留原笔记；兼容矩阵按插件版本展示已验证、部分兼容、待验证或不支持，下载状态不等于可运行状态。

## 5. 功能需求

### FR-01 请求合同

每次请求必须含 `contractVersion`、`intent`、`input`、`mode`、`requestedCapabilities`、`idempotencyKey`，并通过 context 带 `actor`、`spaceId`、`sessionId`、`threadId`、`requestId`、`scopes`、`resourceUris`、`budget` 和 `locale`。缺少 spaceId 必须拒绝。

### FR-02 能力目录

能力包含稳定 ID、版本、输入/输出 schema、类型、风险、requiredScopes、幂等、dry-run、readback 和 undo 声明。能力必须先进入注册表，再进入 Core 目录；`catalog-policy.js` 过滤敏感、私有、剪贴板和 Core v1 禁止的高影响能力。

### FR-03 计划与审批

`plan` 只生成步骤，不执行副作用。写能力或中高风险能力标记 `approvalRequired`；缺少 scope 返回 `missingScopes` 和 `request_scope:<scope>`。审批只对当前 task 的请求有效，不能转化为全局通行证。

### FR-04 任务状态

任务至少支持 `draft`、`awaiting_approval`、`running`、`verifying`、`paused`、`completed`、`failed`、`cancelled`、`partially_completed`。状态转换必须经过 `assertTaskTransition`，每次转换和能力执行产生事件。

### FR-05 可靠写入

写能力成功后才保存 step 回执；写入 task 必须进行 readback 或明确进入 `partially_completed`。幂等键与规范化请求指纹同时校验；同一键内容不同必须拒绝。

### FR-06 任务隐私

Core 数据库只保存计划摘要、资源哈希、actor/space 元数据、状态和错误摘要。请求正文、完整资源 URI、API Key 和私有文件正文不写入普通审计日志。

### FR-07 全局助手行为

Dock 的任务区只显示脱敏 publicTask，每 6 秒刷新一次，最多显示 8 条最近任务；任务执行不依赖 Dock 生命周期。审批、取消继续复用既有 `FridayConfirmDialog`。聊天区必须有输入框、独立历史、新建会话和恢复续聊；触发器和展开面板可在内容区拖动并记住位置，位置在窗口变化后夹取到可视区。操作与展开不得抢走 Office/编辑器焦点。

### FR-08 UI/UX 保护

Core 只固定 command/event/task/result 合同，不固定页面布局。新增 Dock 使用现有主题变量、无障碍 label、窄窗口宽度约束和 reduced-motion 规则；不注入鼠标、不操作 Office WebContentsView、不改变原编辑器焦点和快捷键。

### FR-09 会话事实源与范围

会话和消息必须拥有稳定 ID。主应用以现有 `sessions/messages` 为事实源，按 `scope + scopeKey` 读取与写入；Office vendor 的项目聊天存储须建立同文件多会话关联，或者明确、可迁移地映射到统一事实源。列表、消息读取、发送、改名和删除都由主进程复核 scope，不能只在前端过滤。旧会话迁移先备份，再核对 session/message/附件数量；重复迁移不得制造副本。

### FR-10 历史列表与会话生命周期

六类窗口均提供一致的历史信息架构：历史入口、可选列表、当前条目、搜索、新建对话、重命名、置顶、归档、软删除与恢复。原页面布局可以不同，但用户能逐条打开、切换并继续。空会话不与上一条复用；历史响应晚到不能覆盖较新选择。发送中切换时须取消或明确保留原请求状态。续聊保留原模型/Agent 上下文与工具回执，不重复执行已完成写操作。

### FR-11 模型与 Office 错误语义

Friday 与 Office/PDF 读取当前模型的有效 baseUrl、modelName、apiKey；Office 配置同步失败应归为本地配置，不显示网络断开。鉴权、模型参数、429、5xx、DNS、代理、TLS 和超时错误使用同一错误分类合同；只有连接/传输失败可显示“无法连接 AI 服务”。无输出且无副作用的请求可有限重试；已输出或执行工具后需显式恢复，不能自动重放。

### FR-12 标题状态

新会话立即提供首条用户消息生成的 fallback，异步 AI 标题可优化并重试。手动命名优先级最高，晚到的自动标题不可覆盖。Office 会话标题与 Office 文档显示标题、磁盘文件名分别保存；后两者不因聊天标题变化而更名。空/损坏文档回退文件名或本地化新建文档标题。

### FR-13 Typewriter 资源与性能

Typewriter 先提供可编辑表面，再加载视觉、插件、声音和图片。图片只通过允许的受控资源 URL 或已验证的安全源加载；笔记资源解析拒绝路径穿越和指向外部的符号链接。图片插入、预览、普通笔记视图和重开须一致。性能报告记录设备、文档规模、冷/热进入、输入延迟和 P95；音频失败不阻塞输入，中文 IME、撤销与焦点需真实交互验收。

### FR-14 插件生命周期与兼容

插件状态分为下载、校验、待授权、启用、运行、失败和停用；状态只能由真实 host 事实推进。启用前校验 manifest/入口/版本/权限；停用后撤销事件、命令和定时器。兼容矩阵须包含插件及宿主版本、测试 API、结论、限制和回退路径。

### FR-15 全局助手设置与 Agent

设置持久化 `visible`、`appearance`、`mode`、`agentId` 并提供中英文文案；Dock 响应设置变化。选定 Agent 只影响新请求；后端若没有可用的 Agent 路由，则以明确的回退提示展示实际 AI Core 调度，不伪装成功切换。UI 中的“分身模式”必须有对应执行语义或被标明为仅偏好设置。

## 6. 指标与发布门禁

## 7. 回滚

回滚单位为 Core Facade、任务控制 IPC、Dock 挂载、会话与 Office ProjectStore 迁移、Typewriter 图片协议和插件 host；保留任务记录、笔记、会话、图片、Office 文件、模型配置和备份副本。任务在回滚前应先取消或暂停在检查点，数据库迁移失败恢复最近备份；Office 多会话映射保留旧单会话读取兼容。回退或卸载不得删除用户文件，插件更新保留可恢复的旧版本。

## 8. Preview.21 实施结果

本轮按以上 PRD 完成了以下用户旅程：

- 六类 AI 窗口都可以在自己的历史范围内新建、选择、恢复和继续对话；Office Docs、Sheets、Slides、PDF 由 HappyOffice ProjectStore 绑定文件并支持同文件多条会话。
- Office 助手沿用 Friday 的 DeepSeek 配置，配置缺失、鉴权、限流、服务端和传输错误分开呈现；流中断保留已收到正文，避免重复发送。
- Dock 增加输入框和自己的历史列表，折叠按钮与标题栏都可在应用内容区拖动，位置自动约束；Office overlay 由主进程移动，避免遮挡和点击穿透错误。设置包含隐藏/显示、默认/简洁形象、Friday/Researcher/Auto 模式，并在后端自动调度时显示真实回退说明。
- Typewriter 采用受控图片协议，预览与编辑状态、焦点和路由返回保持一致；输入热路径不等待舞台重绘、图片解码或声音恢复。真实 Electron 报告的输入事件 P95 为 5.5ms。
- Obsidian 隔离宿主补齐常用公开 API；固定的 10 个社区插件安装、启用、停用和重启全部通过，矩阵与原始报告随版本提交。

Preview.21 已完成代码、文档和 Office 子模块交付。最终 Windows x64 安装器、包内原生模块审计、安装版工作区探针和 GitHub Release 已写回交付记录；安装器未配置代码签名，用户可用 SHA256 校验下载内容。
