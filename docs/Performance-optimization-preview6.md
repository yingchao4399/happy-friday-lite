# 3.0.6-preview.6 性能补充

## 主进程首屏调度

自动化、Obsidian 同步和提醒调度器不再在窗口首屏期间同步导入和启动。它们现在在主窗口 `ready-to-show` 后延迟 1.2 秒加载；关闭应用时仍统一停止，数据库任务和定时配置保持不变。这样可以把首屏渲染、剪贴板监听和 Office 主机初始化从后台调度器的数据库读取竞争中解耦。
