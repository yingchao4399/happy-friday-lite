# 剪贴板创建、多选与分享开发验收记录

日期：2026-10-23。目标版本：开发中的 `3.0.6-preview.2`。

## 问题与修复

- 常用语新建和编辑：表单将 Vue 响应式标签数组直接传给 Electron IPC，导致克隆失败，请求无法到达主进程。改为传输普通数组。
- 保存后看不到结果：自动切换到常用语列表，并清除搜索、类型、分类、标签和日期筛选。
- 分类、标签新建入口：页面提供明确文字按钮；管理弹窗的创建表单固定在底部，不随长列表滚走。成功及重名均显示反馈。
- 剪贴板设置：录屏目录数组存在同类 IPC 克隆问题，同步改为普通数组。

## 图片、富文本与媒体开发验收

命令：`node_modules/.bin/electron.cmd scripts/probe-clipboard-media-ui.mjs`。使用隐藏 Electron 窗口、独立临时数据库、真实 preload/IPC、Canvas 和 Chromium 媒体解码器；不操作用户窗口和系统剪贴板。链接打开会拦截 `shell.openExternal` 并核验 URL，不启动用户浏览器。

- 图片：滚轮放大、拖动边界；画笔后撤销/重做、添加文字、马赛克、裁切、旋转；保存图像的原始像素与画布逐字节比较，原始 PNG 保留。
- 640/420 宽图片预览和 420 宽编辑器的底部按钮完整可见，使用官方主题变量及原有弹窗动效；截图在动画结束后捕获。
- 富文本：原先未注册图片节点、导致正文图片丢失。现接入同一预览编辑器；旋转后保存保留正文，二维码不再错误降级为纯文本二维码，分享页图片下载读回尺寸正确。外部图片自动预览不发网络请求，点击后载入，缓存受管 PNG；错误、超限、敏感/过期条目均有测试。
- 正文取消：未保存草稿取消后恢复原有正文与图片；正文编辑中不允许同时保存图片，避免相互覆盖。
- 合并条目：各片段的 HTML 图片按顺序纳入索引，支持预览、编辑和分享；修改合并副本不会改变原条目。前后端图片顺序一致有专项测试。
- 网页/本地图片点击载入后保存受管缓存引用，进程重建后可直接读本机缓存，不再次访问来源；缓存路径经过受管 PNG 路径校验。
- 代码：详情编辑保留缩进和末尾换行，保存副本不改源文件。
- 链接：单击向系统打开接口提交正确 URL，双击进入编辑并保存新链接。
- 音视频：生成真实 WAV 和 VP8 WebM，实际播放时 currentTime 前进，暂停后跳转到指定位置，等待 seeking 完成。

截图：`app-data/diagnostics/clipboard-image-editor-420.png`、`clipboard-media-ui.png`。这些结果证明开发路径可用，仍需最终安装版鼠标/键盘/触控板及常用真实文件验收。

## 桌面入口、真实外部粘贴与笔记归档验收

- `scripts/probe-clipboard-desktop.mjs`：真实 Vue/preload/IPC，注入发送适配器检查目标切换、失败保留位置、敏感确认、520/360 宽浮窗与菜单；真实创建和销毁系统托盘。
- `scripts/probe-clipboard-lifecycle.mjs` 及 `--test-background`：导入完整主进程，隔离数据，验证主窗口关闭退出、启用后台模式且托盘可用时隐藏、显式退出不被拦截。
- 原生 Windows 实机：用独立测试运行目录加载当前 dist 和主进程，外部合成输入窗口复制后按 Ctrl+Shift+V，浮窗显示来源/目标，点击粘贴后逐字一致。完整管理页进入多选，Ctrl+A 实际选中两条；顺序粘贴依次发送至同一外部窗口，最终选中文字与两条内容按顺序拼接完全一致。只发送 Ctrl+V，没有提交回车。该运行目录不是最终安装包，不算安装版验收。
- 顺序粘贴仅保存条目 ID，锁定原目标；发送成功才推进。失败暂停、保留位置，暂停/恢复/跳过/取消与并发取消有自动测试；可选队列快捷键默认未启用。目标 HWND 不暴露给渲染进程。
- `scripts/probe-clipboard-note-ui.mjs`：使用原版 NoteEditor，验证富文本表格、格式、两张图片实际加载、编辑保存重载、旧笔记复用、正文变化与显式加载图片后保存新快照。修复原编辑器默认拒绝 base64 图片造成的图片丢失。
- `scripts/probe-clipboard-real-model.mjs`：在内存中读取现有 DeepSeek 配置，使用合成学习材料、临时数据库，真实发出两次模型请求、对两张图片执行 Windows OCR，保存可重开的富文本多图笔记。敏感样本在联网前拒绝；未将密钥复制到测试目录或输出。
- 笔记归档保留全部受支持图片、结构与来源；未显式载入的外部图片保留来源占位及提示，不后台下载。源内容或隐私状态在 AI 处理中变化时拒绝旧结果，编辑与追加清除旧归档标记。

证据：`app-data/diagnostics/clipboard-quick-{520,360}.png`、`clipboard-note-ui.png`、`clipboard-real-model.json`。测试运行目录和验收数据不进入安装包。
